# WinSCP dependency

WinSCP.exe and both lib/WinSCPnet.dll builds are from the official WinSCP 6.5.7 NuGet package, https://www.nuget.org/packages/WinSCP/6.5.7 (downloaded 2026-10-05). Keep these files at matching versions. WinSCP.com is a legacy console launcher retained for historical compatibility; the module uses WinSCP.exe /console.
